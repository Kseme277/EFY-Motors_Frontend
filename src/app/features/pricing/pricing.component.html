Questions Fréquentes

Quels sont les documents requis ?

Pour une location, une pièce d'identité valide et un permis de conduire de plus de 2 ans sont nécessaires. Pour un achat, nos conseillers vous accompagneront pour les formalités administratives.

Le carburant est-il inclus ?

Le carburant n'est pas inclus dans le tarif de base. Le véhicule est fourni avec le plein et doit être restitué dans le même état, ou un forfait pourra être appliqué.
